# Objects Types / Data Types

- Number : 1234, 3.1415, 3+4j, 0b111, Decimal(), Fraction(), etc.
- String : 'Hello', "Bob's", '''Python''', """Programming""", b'a\x01c', u'sp\xc4m', etc.
- List : [1, 2, 3], [1, 'a', 3.14], [1, [2, 'Three'], 4.5], list(range(5)), list('abc'), etc.
- Tuple : (1, 2, 3), (1, 'a', 3.14), tuple('spam), namedtuple, etc.
- Dictionary : {'a': 1, 'b': 2}, dict(a=1, b=2), dict.fromkeys(['a', 'b'], 0), etc.

- Set : {1, 2, 3}, {1, 'a', 3.14}, set('abc'), frozenset([1, 2, 3]), etc.

- file : open('file.txt', 'r'), open('file.txt', 'w'), open('file.txt', 'a'), etc.

- Boolean : True, False
- None : None
- Function, module, classes, etc.

- Advance: Decorators, Generators, Iterators, Metaprogramming, etc.
